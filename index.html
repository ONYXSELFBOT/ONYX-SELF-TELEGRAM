ONYX SELF چیست؟

ONYX SELF یک سلف‌بات قابل شخصی‌سازی برای تلگرام است که مجموعه‌ای از ابزارهای مدیریتی، اتوماسیون، CRM، فروش، تحلیل، مدیریت محتوا، ابزارهای شخصی و سیستم کنترل لوکال را در یک محیط واحد فراهم می‌کند.

سیستم با رویکرد Privacy-First طراحی شده است. هیچ اطلاعات حساسی داخل سورس‌کد قرار نمی‌گیرد و تنظیمات روی محیط شخصی کاربر نگهداری می‌شوند.

  • اطلاعات حساس داخل سورس‌کد قرار نمی‌گیرند
  • راه‌اندازی اولیه در اولین اجرا با Setup Wizard انجام می‌شود
  • کاربر اطلاعات خودش را در محیط شخصی وارد می‌کند
  • تنظیمات روی محیط شخصی کاربر نگهداری می‌شوند
  • قابلیت‌های AI اختیاری هستند و بدون آن‌ها هم کار می‌کند
  • پروژه Open Source و قابل بازبینی است
  • روی Android (Termux) و Linux قابل اجرا است

آموزش نصب

نصب ONYX SELF

مراحل نصب را به‌ترتیب دنبال کنید. اگر روی کامپیوتر Linux نصب می‌کنید، مرحله Termux را رد کنید.

۱

نصب Termux (برای Android)

Termux یک محیط Terminal برای Android است که امکان اجرای دستورات Linux و Python را فراهم می‌کند. برای اجرای ONYX روی اندروید ضروری است.

⬇ دانلود Termux از F-Droid
ℹ

Termux را از F-Droid دانلود کنید. نسخه Google Play به‌روز نیست و ممکن است مشکل داشته باشد.

۲

آپدیت و نصب پیش‌نیازها

پس از باز کردن Termux، ابتدا پکیج‌ها را آپدیت کنید:

bash
$ pkg update && pkg upgrade

سپس Python و Git را نصب کنید:

bash
$ pkg install python git
۳

دریافت پروژه از GitHub

پروژه را با Git Clone دریافت کنید:

bash
$ git clone https://github.com/ONYXSELFBOT/ONYX-SELF-TELEGRAM.git

وارد پوشه پروژه شوید:

bash
$ cd ONYX-SELF-TELEGRAM
۴

اجرای ONYX

پروژه را اجرا کنید. در اولین اجرا، Setup Wizard راه‌اندازی می‌شود و اطلاعات لازم را از شما می‌خواهد:

bash
$ python main.py
اولین اجرا

Setup Wizard — راه‌اندازی اولیه

در اولین اجرا، ONYX به صورت مرحله‌به‌مرحله اطلاعات لازم را از شما دریافت می‌کند.

۱ — اجرای ONYX

با دستور python main.py پروژه اجرا می‌شود و Setup Wizard فعال می‌شود.

۲ — وارد کردن API ID

API ID دریافت‌شده از my.telegram.org را وارد کنید.

۳ — وارد کردن API HASH

API HASH را وارد کنید. این مقدار را محرمانه نگه دارید.

۴ — شماره تلفن

شماره تلفن مرتبط با حساب تلگرام خود را با کد کشور وارد کنید.

۵ — کد تلگرام

تلگرام یک کد تأیید ارسال می‌کند. آن را وارد کنید.

۶ — رمز دومرحله‌ای (در صورت فعال بودن)

اگر Two-Step Verification فعال دارید، رمز را وارد کنید.

۷ — AI API (اختیاری)

اگر می‌خواهید از قابلیت‌های هوش مصنوعی استفاده کنید، API Key خود را وارد کنید. در غیر این صورت می‌توانید رد کنید.

۸ — انتخاب Timezone

منطقه زمانی خود را برای نمایش صحیح ساعت و تاریخ انتخاب کنید.

۹ — راه‌اندازی کامل

ONYX آماده است. سیستم شروع به کار می‌کند.

API تلگرام

دریافت API ID و API HASH

برای استفاده از ONYX به API ID و API HASH تلگرام نیاز دارید. این اطلاعات رایگان و از طریق سایت رسمی تلگرام قابل دریافت هستند.

۱

ورود به سایت تلگرام

به آدرس my.telegram.org مراجعه کنید.

۲

ورود با شماره تلفن

شماره تلفن مرتبط با حساب تلگرام خود را وارد کنید. این باید همان حسابی باشد که قرار است ONYX روی آن اجرا شود.

۳

ورود به API Development Tools

پس از ورود، گزینه «API Development Tools» را انتخاب کنید.

۴

ساخت Application جدید

فرم ایجاد Application را پر کنید:

  • App title — عنوان دلخواه برای Application
  • Short name — نام کوتاه (فقط حروف و اعداد)
  • Platform — گزینه Other را انتخاب کنید
۵

دریافت API ID و API HASH

پس از ایجاد Application، API ID و API HASH نمایش داده می‌شوند. این مقادیر را کپی و در محیطی امن نگهداری کنید.

⚠ هشدار امنیتی

  • API HASH را هرگز با دیگران به اشتراک نگذارید
  • این مقادیر را داخل GitHub Commit نکنید
  • از این اطلاعات فقط در Setup Wizard استفاده کنید
ورود تلگرام

فرآیند Login تلگرام

در هنگام راه‌اندازی، ONYX از شما می‌خواهد به حساب تلگرام خود وارد شوید. این فرآیند فقط یک‌بار انجام می‌شود.

۱

شماره تلفن

شماره تلفن خود را با کد کشور وارد کنید. مثال: +989123456789

۲

دریافت کد تأیید

تلگرام یک کد به حساب شما ارسال می‌کند. این کد در پیام‌های تلگرام شما (از طریق اکانت Telegram خودتان) ظاهر می‌شود.

۳

وارد کردن کد

کد دریافت‌شده را وارد کنید.

⚠ مهم

  • کد ورود تلگرام را در اختیار هیچ‌کس قرار ندهید
۴

رمز دومرحله‌ای (در صورت نیاز)

اگر Two-Step Verification فعال دارید، رمز آن را وارد کنید.

⚙

Setup

اجرای مجدد Setup

برای اجرای مجدد Setup Wizard از دستور زیر استفاده کنید:

bash
$ python main.py --setup
📋

دستورات فعال بسته به نسخه و قابلیت‌های فعال ONYX ممکن است متفاوت باشند. برای مشاهده لیست به‌روز دستورات به GitHub پروژه مراجعه کنید.

امنیت

نکات امنیتی مهم

حفظ امنیت اطلاعات شخصی در استفاده از ONYX اهمیت بالایی دارد. این موارد را جدی بگیرید.

⚠ اطلاعاتی که هرگز نباید عمومی شوند

  • API ID تلگرام
  • API HASH تلگرام
  • Telegram Session
  • شماره تلفن حساب
  • AI API Key
  • Bot Token (در صورت وجود)
  • رمز عبور
  • رمز Two-Step Verification
  • فایل‌های تنظیمات شخصی
❌ اشتباه — نگذارید در کد
API_ID = 12345678
API_HASH = "abcdef..."
PHONE = "+989..."
✓ صحیح — از Setup Wizard استفاده کنید
اطلاعات در Setup Wizard
وارد می‌شوند و روی
سیستم شخصی ذخیره می‌مانند.
🔒

هرگز این اطلاعات را داخل GitHub Commit نکنید. فایل‌های تنظیمات را به git اضافه نکنید.

رفع مشکل

مشکلات رایج و راه‌حل

اگر با مشکلی روبرو شدید، موارد زیر را بررسی کنید.

  • نسخه Python را بررسی کنید: python --version
  • مطمئن شوید Python 3.x نصب است
  • Dependency‌های پروژه را نصب کنید
  • Log‌های خطا را در Terminal بررسی کنید
  • مطمئن شوید داخل پوشه پروژه هستید
  • API ID را با دقت بررسی کنید (فقط عدد است)
  • API HASH را مجدداً از my.telegram.org کپی کنید
  • مطمئن شوید Application را در حساب صحیح ساخته‌اید
  • اگر Application تازه ساخته‌اید، چند دقیقه صبر کنید
  • شماره تلفن را با کد کشور صحیح وارد کنید
  • اتصال اینترنت را بررسی کنید
  • صندوق پیام تلگرام خود را بررسی کنید (کد در پیام‌های Telegram می‌آید)
  • چند دقیقه صبر کنید و دوباره تلاش کنید
  • فایل Session موجود را حذف کنید
  • Setup را با دستور python main.py --setup دوباره اجرا کنید
  • از حساب تلگرام خود در برنامه رسمی تلگرام خارج نشده باشید
  • API Key را بررسی کنید (منقضی نشده باشد)
  • Provider انتخاب‌شده را بررسی کنید
  • Feature AI را از Local Control Tower فعال کنید
  • اتصال اینترنت را بررسی کنید
  • مطمئن شوید ONYX در حال اجرا است
  • آدرسی که در Terminal نمایش داده شده را استفاده کنید
  • Log‌های ONYX را بررسی کنید
  • تنظیمات Local Server را از Setup بررسی کنید
  • داخل پوشه پروژه بروید
  • دستور git pull را اجرا کنید
  • در صورت نیاز Dependency‌ها را دوباره نصب کنید
سوالات متداول

پرسش‌های رایج

ONYX SELF یک سلف‌بات قابل شخصی‌سازی برای تلگرام است. مجموعه‌ای از ابزارهای مدیریتی، اتوماسیون، CRM، هوش مصنوعی و امنیت شخصی را در یک محیط واحد فراهم می‌کند.
سورس‌کد پروژه به‌صورت عمومی در GitHub در دسترس است. برای اطلاعات بیشتر به مخزن GitHub پروژه مراجعه کنید.
خیر. ONYX SELF یک سلف‌بات است و با API رسمی تلگرام کار می‌کند. به Bot Token نیازی ندارد.
از سایت رسمی my.telegram.org می‌توانید آن‌ها را دریافت کنید. راهنمای کامل در بخش «آموزش دریافت API» همین صفحه موجود است.
خیر. هیچ اطلاعات حساسی داخل سورس‌کد قرار نمی‌گیرد. اطلاعات شما در Setup Wizard وارد و روی سیستم شخصی خودتان نگهداری می‌شوند.
بله. قابلیت‌های AI اختیاری هستند. سیستم بدون AI API نیز به‌خوبی کار می‌کند.
با دستور python main.py --setup می‌توانید Setup Wizard را مجدداً اجرا کنید.
بله. با نصب Termux روی Android می‌توانید ONYX را روی گوشی اجرا کنید.
بله. هر قابلیت را می‌توان از Local Control Tower جداگانه فعال یا غیرفعال کرد.
رابط کاربری محلی ONYX است که امکان مدیریت، مانیتورینگ و تنظیم تمام بخش‌های سیستم را فراهم می‌کند.
داخل پوشه پروژه بروید و دستور git pull را اجرا کنید.
