# 🖤 ONYX Self

### سلف‌بات قدرتمند، هوشمند و قابل شخصی‌سازی برای تلگرام

**ONYX Self** یک سلف‌بات پیشرفته برای تلگرام است که مجموعه‌ای از قابلیت‌های هوشمند، امنیتی، مدیریتی، فروش، CRM، ابزارهای کاربردی و یک **پنل کنترل لوکال** را در یک سیستم واحد جمع می‌کند.

> ⚡ یک سلف‌بات
> 🧠 قابلیت‌های هوشمند
> 🛡️ سیستم‌های امنیتی
> 🎛️ پنل کنترل لوکال

---

* 🍯 **Honeytrap Detector** — شناسایی رفتارهای مشکوک
* 🛠️ **Command Studio** — مدیریت و ساخت دستورات سفارشی
* 🫥 **Invisible Watermark Engine** — سیستم واترمارک نامرئی
* 🔗 **Smart Link Intelligence** — تحلیل هوشمند لینک‌ها
* 📦 **Universal Exporter** — خروجی گرفتن از اطلاعات
* 📥 **Universal Capture** — دریافت و تشخیص هوشمند محتوا
* 📡 **Personal Radar** — شناسایی اتفاقات مهم

* ⏪ **Event Replay** — بازسازی زنجیره رویدادها

* 🤖 **اتصال به هوش مصنوعی**

قابلیت‌های جدید نیز در حال توسعه و اضافه شدن هستند.

# 🚀 نصب و اجرا

## ۱. دریافت پروژه

ابتدا Repository را دریافت کنید:

```bash
git clone آدرس-مخزن-گیتهاب
```

و وارد پوشه پروژه شوید:

```bash
cd نام-پروژه
```

---

## ۲. اجرای سلف

فایل اصلی را اجرا کنید:

```bash
python main_v11.py
```

در اولین اجرا، سلف به‌صورت خودکار متوجه می‌شود که هنوز تنظیم نشده است و **Setup Wizard** را اجرا می‌کند.

---

# ⚙️ راه‌اندازی اولیه

در اولین اجرا اطلاعات موردنیاز از شما دریافت می‌شود:

```text
API ID تلگرام
API HASH تلگرام
شماره تلفن
کد ورود تلگرام
رمز تأیید دومرحله‌ای در صورت فعال بودن
API هوش مصنوعی در صورت نیاز
منطقه زمانی
```

لازم نیست این اطلاعات را داخل کد قرار دهید.

اطلاعات تنظیمات روی سیستم خودتان ذخیره می‌شوند.

در اجراهای بعدی، اگر تنظیمات معتبر باشند، سلف مستقیماً اجرا می‌شود.

---

# 🔐 امنیت

**اطلاعات حساس خود را داخل GitHub قرار ندهید.**

هرگز این موارد را منتشر نکنید:

```text
API ID
API HASH
Session تلگرام
شماره تلفن
API Key هوش مصنوعی
Bot Token
رمز عبور
فایل‌های تنظیمات شخصی
```

Session تلگرام را مانند رمز عبور در نظر بگیرید و در اختیار دیگران قرار ندهید.

# 🤖 هوش مصنوعی

ONYX قابلیت اتصال به سرویس‌های هوش مصنوعی را دارد.

در صورت تنظیم API، قابلیت‌های مختلف می‌توانند از هوش مصنوعی برای مواردی مانند:

* تحلیل
* پردازش محتوا
* پاسخ هوشمند
* کمک به فروش
* تحلیل محصولات
* پردازش تصاویر
* اتوماسیون

استفاده کنند.

قابلیت‌هایی که به هوش مصنوعی نیاز ندارند، بدون API نیز قابل استفاده هستند.

# 🖥️ پنل کنترل لوکال

ONYX دارای یک **پنل کنترل لوکال** است که مدیریت سلف را ساده‌تر می‌کند.

بعد از اجرای سلف، پنل را از طریق آدرس زیر باز کنید:

```text
http://127.0.0.1:8880
```

در این پنل می‌توانید بخش‌هایی مانند موارد زیر را مدیریت و مشاهده کنید:

* 🟢 وضعیت سلف
* ⚙️ قابلیت‌های فعال و غیرفعال
* 🤖 تنظیمات هوش مصنوعی
* 🛒 فروش
* 👥 CRM
* 🛡️ امنیت
* 📋 لاگ‌ها
* 🩺 سلامت سیستم
* ⏰ ساعت و تاریخ
* 🎮 بازی‌ها
* ⚡ وضعیت عملیات
* 📊 اطلاعات سیستم

هدف پنل این است که مدیریت قابلیت‌های سلف بدون نیاز به استفاده مداوم از دستورات انجام شود.
