# 📱 نصب روی اندروید با Termux

برای اجرای ONYX روی گوشی اندرویدی می‌توانید از **Termux** استفاده کنید.

> ⚠️ پیشنهاد می‌شود Termux را از منبع معتبر دریافت کنید و از نسخه‌های ناشناس استفاده نکنید.

بعد از نصب Termux، آن را باز کنید و دستورات زیر را اجرا کنید.

## ۱. به‌روزرسانی Termux

```bash
pkg update && pkg upgrade -y
```

## ۲. نصب Python و Git

```bash
pkg install python git -y
```

## ۳. دریافت پروژه

```bash
git clone https://github.com/ONYXSELFBOT/ONYX-SELF-TELEGRAM.git
```

## ۴. ورود به پوشه پروژه

```bash
cd ONYX-SELF-TELEGRAM
```

## ۵. اجرای ONYX

```bash
python main.py
```

اگر پروژه در اولین اجرا نیاز به نصب وابستگی داشته باشد، سیستم Setup آن‌ها را بررسی و در صورت امکان نصب می‌کند.

# 🔑 دریافت Telegram API ID و API HASH

برای اجرای سلف با Telegram API، باید API ID و API HASH مخصوص خودتان را دریافت کنید.

### مرحله ۱

با حساب Telegram خود وارد بخش **Telegram API Development Tools** شوید.

### مرحله ۲

گزینه:

```text
API development tools
```

را انتخاب کنید.

### مرحله ۳

اگر قبلاً Application نساخته‌اید، فرم ساخت Application را تکمیل کنید.

مواردی مانند:

```text
App title
Short name
Platform
```

از شما درخواست می‌شود.

### مرحله ۴

بعد از ساخت Application، Telegram اطلاعات زیر را به شما نمایش می‌دهد:

```text
api_id
api_hash
```

### مرحله ۵

این دو مقدار را هنگام اجرای ONYX وارد کنید:

```text
API ID:
>

API HASH:
>
```

> 🔐 API HASH را مثل رمز عبور در نظر بگیرید و در اختیار دیگران قرار ندهید.

> ⚠️ برای هر Application از API ID و API HASH خودتان استفاده کنید و اطلاعات حساب خود را داخل Repository قرار ندهید.

# ⚙️ راه‌اندازی اولیه ONYX

در اولین اجرا، ONYX به‌صورت خودکار متوجه می‌شود که هنوز تنظیم نشده است و Setup Wizard را اجرا می‌کند.

```text

```

### روند کلی:

```text
شروع ONYX
      ↓
تشخیص First Run
      ↓
دریافت تنظیمات
      ↓
اتصال به Telegram
      ↓
ساخت/ذخیره Session محلی
      ↓

      ↓
اجرای ONYX
```

در اجراهای بعدی، اگر تنظیمات و Session معتبر باشند، نیازی به وارد کردن دوباره اطلاعات نخواهد بود.
